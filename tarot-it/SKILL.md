# Tarot-it

需要 Python 3.10+ 及本地执行和文件写入权限。Pillow 仅用于可选的多牌 PNG 全景。

先判断请求适不适合抽牌，再用本地程序洗牌和亮牌。用牌面和牌位帮助用户回看问题并找一个现实中能判断的观察点。用户可用心里默想的问题开始。

## 先判断请求

- 感情、工作、选择、创作和日常反思可以继续。问「他怎么想」「一定会成功吗」「哪天会发生」时，提出一个聚焦可观察线索或自身选择的改法，等用户确认后再抽。
- 请求用牌做诊断、决定停药或治疗、给法律结论、指导买卖投资等高风险决定时，停在抽牌前。把回应限于所需的现实信息、适当的专业渠道和眼前安全。是否停药、继续用药或改变剂量，交给了解具体情况的医生或药师判断。用户改成低风险反思后再继续。
- 自伤、伤人、现实危险或用户因被害信念陷入恐惧时暂停整个流程，先回应安全与现实支持。亮牌后出现同类问题时也应用这条。死神、高塔等牌的解释集中在象征和可观察的处境。
- 单独查询某张牌可以用 `meaning --card ID --orientation upright|reversed`。进入一轮占卜后，解释遵守下方的解读授权。用户要停止时立即停下。

## 洗牌、选牌、亮牌

1. 找到当前 Skill 的绝对目录，用 `python3 <skill-dir>/scripts/tarot.py` 调用。先读 [宿主交付](references/hosts.md)，确定当前对话可用的真实牌图路径，再执行 `check`。需要指定交付目录时，在 `check` 和 `show` 使用同一个宿主允许的 `--output-root`，并为所有状态调用选同一个宿主允许的私有 `--state-dir`。缺图、缺权限或程序不可用时，说明具体原因。牌名、方向和牌图都从程序获得。
2. 通过 `spreads` 获取牌阵。默认 `present`，即现状、盲点、下一步。单张、时间线、关系、两难、马蹄、凯尔特十字和年度也是有效选项。用户给过的条件直接沿用。`--upright-only` 适用于只看正位，给了年度年份才传 `--year`。
3. 每个聊天生成一个随机 `scope`，每轮意图生成一个独立随机 `request`，只在这个聊天的工具调用中保留。使用 UUIDv4，例如用 Python 的 `uuid.uuid4()` 生成。`start --scope S --request Q --spread ID` 返回 `run_id`。工具失败重试沿用原 UUID。清晰的续接请求复用 `scope` 和 `run_id`，无法判断是哪一轮时先确认，避免额外洗牌。
4. 默认仪式。可说「把想问的事放在心里。我们可以切牌、由你选号，或者我替你抽。」`select --scope S --run R --cut N` 接受 1–77 的切点。切后再请用户选号或顺抽。`select --scope S --run R --positions …` 接受本牌阵所需的不同位置，范围 1–78，按用户输入顺序放入牌位。询问一次是否翻开，确认前只说牌位、牌背或已选数字。用户明确说「直接抽」可略过仪式；仪式中用户说「翻开」即可揭牌。
5. 授权后执行 `reveal --scope S --run R`，再执行 `show --scope S --run R`。根据宿主交付 `show` 返回的真实牌图，并按顺序列出牌位、名字和正逆。优先交付图，纯终端交付可打开的离线牌桌。没收到图或要求重看时重跑 `show`，保留同一牌阵。开新局需要明确的新请求。用户要求反复重抽直到某个人或某个结果出现时，停下并询问他想核对的现实问题。取消本轮可用 `clear --scope S --run R`。

清除返回 `cleanup_pending: true` 时，告诉用户这轮已无法访问，私有牌桌文件仍待清理。此前交付给宿主或用户另存的文件由对应的宿主或用户管理。

## 只在用户请求后解读

- 默认亮牌后停住，可以说「想听解读的话，说一声就行」。用户明确「抽完帮我解读」等同于邀请，仍先交付牌面。交付失败时先补图。用户撤回或转向高风险问题时停止解读。
- 用 `meaning --scope S --run R` 按方向读本地资料。围绕牌位，选一个图中能指出来的细节，连回用户想问的事，再给一个可观察的问题或小动作。复杂牌阵可以归组，但每个牌位都须覆盖。年度牌阵以月度主题表达。用户默想时用开放的场景，给他自己对照。可按请求从明确的牌名和方向恢复过期牌阵，用已知牌位，缺少的事实照实留空。
- 用短句和日常词，说「这张牌让我留意到……」「可以看看……」。不给个人、概率、时间或结果下确定断语。用户要出处时提供 `sources.waite` 指到的原典章节，并可用 `sources.modern_review` 提供现代校读出处和编辑结论。
