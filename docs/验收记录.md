## 工程和素材

- Git 已在项目目录初始化为 `main`。先完成 [实施规格](SPEC.md)，再实现共用 Skill 和运行器。
- 78 张 Pam-A 原图逐张对照 Wikimedia Commons 原始 SHA-1 并记录 SHA-256。逐张解码、核尺寸并用五张缩略图总览检查编号、花色、画面和裁切。宽 1090–1144 像素，高 1919–1920 像素。另有 156 张方向预览。
- 共 78 份中文牌义、156 个正逆位释义。Eric 确认替代来源后，逐牌对照 Biddy Tarot 官网全套索引，两种牌向均覆盖。Joan Bunning 作者网站第 17 课用来核对逆位方法。保留了权杖四和圣杯八等牌的原典分歧，调整了 8 条原创释义，逐牌留下链接与编辑结论。 [Biddy Tarot 全套索引](https://biddytarot.com/tarot-card-meanings/) · [Bunning 逆位课](https://www.learntarot.com/less17.htm)
- 对用户提供的 `suan` 仓库做了只读核验。其完整文件树有 296 条记录，直接相关内容包括自编的 78 张牌义和 6 条署名韦特的短摘记，未找到 Pollack 或 Greer 书稿。该仓库未作为牌图或牌义来源。 [仓库经典摘记](https://github.com/huy555huy/suan/tree/main/knowledge/classics) · [仓库塔罗代码](https://github.com/huy555huy/suan/blob/main/computation/tarot.py)
- Python 3.10.20、3.12.13 与 3.14.6 均通过 17 项单元及 CLI 集成测试。覆盖八套牌阵、日期标签、重复和并发揭牌、取消后重试、会话隔离、状态过期、清除、缺图、可选 PNG 降级、无 Pillow 离线牌桌、轻量 ZIP 内容和出错后补传同一结果。Skill 格式已通过校验。
- ZIP 成员 319 个，校验了 SHA-256、目录白名单、重复成员和残留文件。从带空格的干净目录解压，使用 Python `-S` 走通单张、十张和年度牌桌。Chrome 离线模式在 1280 px 和 390 px 下各打开这三份牌桌，确认实际图片解码、可放大和无外部请求。凯尔特交叉牌布局在桌面和窄屏分别验证。
